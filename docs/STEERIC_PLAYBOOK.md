# Steeric: manual-only marketing workflow

This is a marketing **review** toolkit for the Steeric service website (Astro, Sanity content, editorial visual language). It is not a license to rewrite the website or run unrequested campaigns.

## Preferred sequence

| Stage | Manually invoke | Concrete output | Guardrails |
| --- | --- | --- | --- |
| Foundational positioning | `product-marketing`, `customer-research` | A reviewed `.agents/product-marketing.md` with ICP, jobs-to-be-done, buyer objections, voice, and evidence | Draft first; founder approval before committing claims |
| Competitive analysis | `competitor-profiling`, `competitors` | Dated evidence and differentiation options | Respect competitor trademarks; no copycat positioning |
| Technical search hygiene | `seo-audit`, optionally `schema` | Evidence-based indexability, robots, sitemap, canonical, metadata and JSON-LD audit | Do not treat Lighthouse score as SEO performance or infer schema absence from a stripped HTML fetch |
| Information architecture | `site-architecture` | URL map and link plan for Home, Services, AI, Insights, Company | Do not redesign approved navigation without request |
| AI visibility | `ai-seo`, `link-building` | Crawl/accessibility check, citable-first-party evidence plan, prioritised external coverage | No promise of rankings or AI citations; no speculative magic `llms.txt` fixes |
| Editorial content | `content-strategy`, `copywriting`, `copy-editing` | Insights series, concrete outlines, revisions | Original knowledge and evidence; don't manufacture statistics or filler posts |
| Lead funnel | `cro`, `analytics`, `ab-testing` | Contact path review and a minimal measurement plan | No unsolicited form changes or manipulative popups |
| Marketing experiments | `free-tools`, `lead-magnets`, `social`, `launch` | One useful tool or publishable artifact and a distribution plan | Validate demand and maintenance before building |
| Outreach | `prospecting`, `cold-email`, `sales-enablement` | Small, verified, appropriate prospect shortlists and personalized drafts | Compliance, anti-spam and verification; no bulk sends by default |
| Future growth | `programmatic-seo`, `marketing-plan`, `revops` | A justified expansion plan when the business has evidence | No doorway pages; no huge marketing roadmap as busywork |

## Evidence protocol for every marketing recommendation

1. Establish the audience, buyer intent, and primary business outcome for the page or campaign.
2. Inspect the repo and actual rendered site first, then public search results when appropriate. Report what was observed versus inferred.
3. Identify the smallest viable recommendation with an estimated mechanism of impact, evidence, constraints, and test method.
4. **Audit first, change second.** Protect existing design/layout/motion and the production deployment by default.
5. Capture baseline and outcomes; revisit the plan only with new evidence.

## Manual multi-skill use

The upstream skills reference each other as hand-offs. Since every skill here is **manual-only**, manually invoke both if you want two specialists to participate. Examples:

- Codex: `$seo-audit $schema Audit technical SEO and current JSON-LD; report only.`
- Claude Code: `/seo-audit` followed by `/schema` to check a structured-data proposal.
- Codex: `$product-marketing $copywriting Review Steeric's homepage positioning, propose edits in a separate Markdown draft.`

When `seo-audit` says “see `site-architecture`,” the sibling is available, but is not automatically invoked. Direct reading of an approved reference file is distinct from turning on another skill. Each explicitly invoked skill may read its *own* `references/` as part of executing the requested workflow.

## What success looks like

Prioritize **qualified conversations and client trust**, then evidence-backed search visibility and engagement. Vanity traffic, autogenerated article volume, a 100 Lighthouse score, and a long list of installed skills are not business outcomes.
